Container Treatment
Circle Background
Radial gradient fill in midnight purple provides depth. Lighter center fading to darker edge. Unifies all dark variants under the brand purple family.
Borderless Container
No border ring. The gradient glow and shadow layers define the circle edge, creating a cleaner float against dark backgrounds.
Layered Shadow
Four shadow layers: color glow, diffused glow, depth shadow, and inset highlight. These define the circle boundary without a hard border.
Glow Sync
Outer glow hue rotates in sync with the gradient. Creates ambient color bleed effect.

Variation Policy

The logo is static by default. Animation is a signal, not a decoration. The zero-prop default renders paused. Animation turns on only for Pathfinder triggers (all states below) and documented hero / marketing placements. Everywhere else (navigation bars, card headers, sidebars, footer marks, toolbar chrome) the lockup comes from the canonical brand SVGs via StaticLogoLockup and StaticLogoIcon. The tiers below govern speed and glow whenever animation is on. Hover any tier to preview.

Base State DEFAULT
Production default. Ships with zero props. Calm, ambient, professional. This is what the logo looks like when nothing special is happening.
speed=7s glow=0.35 All standard UI, navigation bars, card headers, sidebar, footer marks
WHEN TO USE
No justification needed. This is the starting point.
Hover / Focus Response INTERACTION
Responds to user attention. Subtle acceleration and glow boost while the interaction is active. Must return to base when interaction ends.
speed=4.5s glow=0.5 Hover states, keyboard focus, touch-hold, sidebar nav items
WHEN TO USE
Only while interaction is active. Transition back on blur/leave.
Active / Processing SYSTEM STATE
The system is actively working. Visible energy communicates that something is happening. Reserved for moments when the platform is performing an operation the user initiated.
speed=2.5s glow=0.65 Pathfinder thinking, file generation, form processing, AI operations
WHEN TO USE
Only during active system operations. Never as a resting state.
Hero / Marketing PRESENTATION
Slightly more expressive than base for contexts where the logo is the focal point. Not as energetic as active - this is confident, not busy.
speed=5s glow=0.5 Landing pages, splash screens, investor decks, about pages
WHEN TO USE
Only when the logo is a primary visual element, not tucked into UI chrome.
Minimal / Background REDUCED
The logo is present but should not compete for attention. Barely perceptible rotation. Consider using paused=true for truly static contexts.
speed=12s glow=0.2 Footer marks, background decorations, print layouts, email headers
WHEN TO USE
When the logo must exist but attention belongs elsewhere.
Hard Boundaries
Speed Floor
1.5s minimum
Below 1.5s feels frantic and undermines brand confidence. No exceptions.
Speed Ceiling
15s maximum
Beyond 15s the motion is imperceptible. Use paused=true instead of ultra-slow rotation.
Glow Ceiling
0.85 maximum
Above 0.85 the glow overwhelms the icon shape, especially at lg/xl sizes.
Glow Floor
0.1 minimum (if animated)
Below 0.1 the icon looks broken rather than subtle. Use 0 only with paused=true.
Transition Behavior
Base to Hover
7s / 0.35 → 4.5s / 0.50
Immediate on mouseenter. Return on mouseleave.
Base to Active
7s / 0.35 → 2.5s / 0.65
Ramp over ~300ms. Return over ~500ms on completion.
Any to Base
Current → 7s / 0.35
Always returns to base. Never persists an elevated state.
Implementation Checklist
1.Does the logo render at 7s / 0.35 with zero custom props?
2.If speed or glow deviate from defaults, is there a documented context reason?
3.Does the elevated state return to base when the triggering context ends?
4.Is the speed within the 1.5s-15s hard boundary?
5.Is the glow within the 0.1-0.85 hard boundary?
6.If used as a button (onClick), does it respond to hover per the Hover tier?

Do's and Don'ts
Do
✅Ship with zero-prop defaults (speed=7, glow=0.35) for all standard placements
✅Use variant="pathfinder" (deep purple #2D1B4E fill) for all Pathfinder triggers
✅Reference the Variation Policy when deviating from base state
✅Return to base state when the triggering context ends (hover off, processing complete)
✅Match mode (light/dark) to the surrounding UI theme
✅Use xs (28px) for in-app Pathfinder trigger buttons
✅Use the paused prop for print, email, or static contexts
✅Maintain minimum clear space of 25% of icon size around the logo
Don't
❌Override speed or glow without a documented context from the Variation Policy
❌Use default dark mode fill for Pathfinder (always use variant="pathfinder")
❌Leave an elevated speed/glow state running after the triggering context ends
❌Use speed below 1.5s (feels frantic) or glow above 0.85 (overwhelms the icon)
❌Place on busy backgrounds that compete with the gradient
❌Crop or clip the container circle or re-add a border ring
❌Alter the gradient colors or stop positions
❌Use the animated icon as a replacement for the full wordmark
Accessibility Requirements
Reduced Motion
Component auto-detects prefers-reduced-motion and pauses the animation. No user action required.
Keyboard Navigation
When used as a button (onClick provided), supports Enter and Space key activation with visible focus ring.
ARIA Roles
Renders as role='button' with tabindex when interactive, role='img' when decorative.
Screen Readers
aria-label='Afterpath' announces the element. Inner SVG is aria-hidden.
